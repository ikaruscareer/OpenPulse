# Roadmap — 12-week MVP (distilled from proposal)
Phase 0 (W1): Freeze schema — DONE in v0.1.0 (core/schema/).
Phase 1 (W2-4): Collectors — github, osv, nvd, cve, kev, endoflife, registries + normalization/entity-resolution.
Phase 2 (W3-5): 4 analysts — Change, Security, Evidence, Report (keep separate, no giant agent).
Phase 3 (W5): Bitnami validation — must produce announcement/effective date, affected artifacts/versions, evidence, confidence, recommendation. Gate: do not proceed to SaaS if this fails.
Phase 4-5 (W5-7): OSS Pulse facets + OpenPulse 100 seed (data/openpulse100_seed.yaml).
Phase 6 (W7-8): Monthly report pipeline.
Phase 7-10 (W8-12): Website, free follows + newsletter, customer watchlist, impact engine.
Non-goals W1-12: SAST/SCA, auto-remediation, CI/CD, MCP, Jira, SSO/RBAC, hundreds of ecosystems, risk score, mobile.
